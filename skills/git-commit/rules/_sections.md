# Sections

Rule files are named `<prefix>-<slug>.md`; the file name without `.md` is the rule ID. Cite a rule by its ID.

| # | Section | Prefix | Impact | Covers |
|---|---|---|---|---|
| 1 | Commits | `commit-` | MEDIUM | Messages, what gets staged, line endings, `[ci skip]`, author identity |

Impact is the default severity of a finding; raise it by one level when the repo is public.
