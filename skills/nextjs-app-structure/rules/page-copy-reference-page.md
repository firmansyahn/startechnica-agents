## Copy the reference page, not the nearest page

**Impact: MEDIUM**

Start from the project's named reference page for the kind (list with create/edit, settings, detail, wizard). A page that fetches in `useEffect`, builds its own dialog, spreads state in every `onChange` or calls `alert()` is legacy, however close it is.
