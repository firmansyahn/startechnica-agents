## Empty states say what's missing and what to do

**Impact: LOW** (an empty page looks broken and leaves the user without a next step)

Outside tables, an empty state has a short title, one sentence, and the primary action if the user may take it ("No customers yet. Add the first customer."). Filtered lists with no matches say so and offer to clear the filters.

**How to check:** check empty states have a title, a sentence and the primary action, and filtered lists offer to clear the filters.
