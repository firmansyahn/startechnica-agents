## Selection uses checkboxes with a select-all and a bulk action bar

**Impact: MEDIUM** (unlabelled checkboxes, stale selections acting on rows the user can no longer see)

A checkbox column with a header checkbox (indeterminate when some rows are selected), each labelled ("Select customer North"). Bulk actions appear in a bar showing the count; selection clears after a bulk write and on page or filter change.

**How to check:** check selectable tables for a labelled header and row checkboxes, a bar with the count, and clearing after a bulk write and on page or filter change.
