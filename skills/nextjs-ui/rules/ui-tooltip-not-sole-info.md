## Tooltips only add, never hold, information

**Impact: MEDIUM** (touch and keyboard users never see what only a tooltip says)

Tooltips appear on hover and focus only, so touch users never see them. Anything the user needs (a field's rule, why a button is disabled) is visible text or a description; a tooltip may repeat it.

**How to check:** look for tooltips that carry the only copy of a rule, a reason or a value.
