# Sections

Rule files are named `<prefix>-<slug>.md`; the file name without `.md` is the rule ID. Cite a rule by its ID.

| # | Section | Prefix | Impact | Covers |
|---|---|---|---|---|
| 1 | Go CI quality gates | `goci-` | MEDIUM | Module consistency, integration test caching, vulnerability checks |

Impact is the default severity; raise it one level for a production release pipeline.
